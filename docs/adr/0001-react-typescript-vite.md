# React, TypeScript and Vite

We build the app with React and TypeScript on Vite, tested with Vitest and Testing Library. Svelte was the main alternative and is leaner, but React has the strongest libraries for the hard parts of this app (dnd-kit for accessible drag-and-drop, TanStack Table, vite-plugin-pwa) and matches what most teams use, which matters because this project doubles as practice for a team workflow.
